AXEZENT NanoGap — published repository and Pages enablement

Research author: Shawn Calvin Snelling
Repository: https://github.com/shawncalvinsnelling/AXEZENT-NanoGap-Structural-Architecture

The project files are already on main. Do not upload the old ZIP again.

ONE REQUIRED SETTING:
1. Open the repository on GitHub.
2. Choose Settings > Pages.
3. Under Build and deployment > Source select GitHub Actions.
4. Open the Actions tab, select Publish AXEZENT research website, and rerun the failed workflow if it does not automatically retry.
5. Wait for the deployment to show success; then use the Visit site link under Settings > Pages.

The workflow reconstructs the exact full-resolution photo and the original 38.1 mm calibration STL from lossless parts, verifies SHA256, runs the tests, and publishes the website.

All visible research is credited to Shawn Calvin Snelling.
The 84.8 MB high-resolution master STL remains outside this public website repository and was separately shared directly with the corresponding researchers.
