# Repository files, exact order

1. `index.html` — entry point for GitHub Pages (must be at repo root).
2. `.nojekyll` — serve static assets without Jekyll transformations.
3. `css/site.css` — all responsive design and layout.
4. `js/site.js` — navigation, image viewer, mathematical field explorer (no external dependencies).
5. `assets/images/printed-cube.webp` — photographic specimen image for web use.
6. `assets/images/printed-cube-original.png` — original photo file from author email.
7. `assets/images/cad-render.webp` — original CAD STL render, web-optimized.
8. `assets/images/schematic.svg` — labeled conceptual structural diagram.
9. `assets/models/AXEZENT_Quantum_Cube_v1_Calibration_38p1mm.stl` — actual 38.1 mm calibration geometry.
10. `assets/models/AXEZENT_Quantum_Cube_v1_Outer_Frame_63p5mm.stl` — actual 63.5 mm outer frame component.
11. `assets/documents/AXEZENT_Research_Brief.pdf` — 4-page engineering brief.
12. `source/AXZ_Cube_v1_0_generator.py` — original v1.0 code, no source alterations.
13. `source/AXEZENT_Original_Design_Manifest.json` — copied original JSON manifest.
14. `docs/MATHEMATICS.md` — clarified implemented equations and numerical caveat.
15. `docs/PROVENANCE.md` — attribution and file history.
16. `docs/RESEARCH_STATUS.md` — verified vs open claims.
17. `docs/LAB_TEST_PROTOCOL.md` — lab reproducibility plan.
18. `docs/LIMITATIONS.md` — original numerical limitations.
19. `docs/geometric-audit.json` — high-resolution geometric audit.
20. `docs/SHA256SUMS.txt` — hashes of public binary source artifacts.
21. `docs/RIGHTS_AND_USE.md` — research access notice.
22. `tests/test_site.py` — site integrity checks.
23. `CITATION.cff` — citation metadata.
24. `README.md` — installation instructions and release context.
25. `.github/workflows/research-site-check.yml` — automatic integrity tests on GitHub.
26. `PUBLISH_TO_GITHUB_WINDOWS.bat` — optional Windows Git upload helper; requires explicit confirmation.
